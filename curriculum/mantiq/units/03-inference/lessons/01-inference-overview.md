# Inference and Its Main Types

An **inference** reaches a conclusion through evidence and reasoning. A **direct** or immediate inference starts from one proposition; an **indirect** inference combines multiple propositions.

## Worked example

Obverting “All birds are animals” uses only that proposition, so it is direct. Combining “All birds are animals” with “All sparrows are birds” is indirect.

## Guided check

Count the propositions used as evidence, not the number of sentences in the final answer.

## Takeaway

One starting proposition means direct inference; multiple starting propositions mean indirect inference.
