# Distribution

A term is **distributed** when the proposition speaks about every member of the class named by that term. Universal propositions distribute their subject; negative propositions distribute their predicate.

| Form | Subject | Predicate |
|---|---|---|
| A | distributed | undistributed |
| E | distributed | distributed |
| I | undistributed | undistributed |
| O | undistributed | distributed |

## Worked example

In “Some students are not writers,” only some students are mentioned, so the subject is undistributed. The denial excludes them from the whole class of writers, so the predicate is distributed.

## Guided check

For an E-form, apply both rules independently. Which rule distributes each term?

## Takeaway

Combine the two rules rather than memorising four unrelated rows.
