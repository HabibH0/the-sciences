# Relationships Between Universals

Two universal terms have one of four relations — نِسْبَة (*nisbah*) — according
to how their members compare.

## 1. Equal membership — التَّسَاوِيْ (*al-tasāwī*)

Both universals have exactly the same members.

**Worked example:** *wuḍūʾ* and *ablution*. The sets coincide.

```text
    ╭────────────╮
    │  WUḌŪʾ =   │
    │  ABLUTION  │
    ╰────────────╯
```

## 2. Disjoint membership — التَّبَايُنُ (*al-tabāyun*)

No member of one universal is a member of the other.

**Worked example:** married and unmarried. The sets are separate.

```text
   ( MARRIED )       ( UNMARRIED )
```

## 3. One-way inclusion

**الْعُمُوْمُ وَالْخُصُوْصُ مُطْلَقًا**
(*al-ʿumūm wa-l-khuṣūṣ muṭlaqan*)

Every member of one universal falls under a second universal, but the reverse
is not true.

**Worked example:** every mother is a woman, but not every woman is a mother.
The narrower set sits inside the broader set.

```text
   ╭────────── WOMEN ──────────╮
   │      ( MOTHERS )          │
   ╰───────────────────────────╯
```

## 4. Partial overlap

**الْعُمُوْمُ وَالْخُصُوْصُ مِنْ وَجْه**
(*al-ʿumūm wa-l-khuṣūṣ min wajh*)

Some members are shared, while each universal also has members outside the
other.

**Worked example:** adults and males. Some adults are male, some adults are not
male, and some males are not adults.

```text
       ( ADULTS ( shared ) MALES )
```

## Three membership questions

To classify any pair, ask:

1. Are all members shared in both directions? → equal membership.
2. Are no members shared? → disjoint membership.
3. Are all members of one set inside the other? → one-way inclusion.
4. Otherwise, do they share some members while each has outsiders? → partial
   overlap.
